Data cleaning

# keep only OCC == 1
mavo_occ1 <- mavo %>% filter(OCC == 1)

# split into the dosing rows (TIME == 0) and observation rows (TIME != 0)
dose_rows <- mavo_occ1 %>% filter(TIME == 0)
obs_rows  <- mavo_occ1 %>% filter(TIME != 0)

# total drug for each individual = sum of DV across observation rows
total_Y <- obs_rows %>%
  group_by(ID) %>%
  summarize(Y = sum(DV), .groups = "drop")

# get the baseline characteristics from the dosing row
baseline <- dose_rows %>%
  select(ID, DOSE, AGE, SEX, RACE, WT, HT)

# join total Y with baseline
mavo_clean <- baseline %>%
  inner_join(total_Y, by = "ID") %>%
  mutate(
    SEX = factor(SEX),
    RACE = factor(RACE)
  ) %>%
  select(Y, DOSE, AGE, SEX, RACE, WT, HT)

# Save the cleaned data as an RDS file for downstream exercises
saveRDS(mavo_clean, file = "mavo_clean.rds")

Model critique

Both Model 1 and Model 2 beat the null model on training, CV, and test RMSE, so both extract real signal from the predictors. Model 1 has limited practical utility because DOSE only takes three discrete values, so it can only output three predictions and cannot distinguish individuals at the same dose. Model 2 is a meaningful improvement: it has the lowest RMSE everywhere (train, CV, test), its predictions spread along the 45-degree line, and its bootstrap medians and 89% intervals are stable. Its main limitations are asymmetric residuals at the extremes (suggesting nonlinearity the linear model misses), a small sample (90 train / 30 test), and wider bootstrap intervals in the tails.
